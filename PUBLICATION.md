## Historical initial archive and earlier work

The first release of this audit was initially placed in the earlier knowledge-distillation repository. Its existing Zenodo integration automatically archived that repository under DOI [10.5281/zenodo.23851131](https://doi.org/10.5281/zenodo.23851131), in the earlier repository's version lineage. That software archive is retained for provenance and now identifies the independent preprint and dedicated repository in its metadata. It is not the preferred paper citation.

The earlier knowledge-distillation baseline remains available at the version-specific DOI [10.5281/zenodo.23644783](https://doi.org/10.5281/zenodo.23644783). Do not use the old all-versions DOI to identify the new independent preprint.

No raw experimental records, registered decisions, inference outputs, or model parameters were changed during publication or repository separation. The release tag remains frozen; these publication links and citation metadata are maintained on main.
